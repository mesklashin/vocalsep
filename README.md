# French Rap Vocal Separation Tool

Academic project focusing on separating vocal and musical tracks from French rap recordings using Demucs, optimized for transcription with Whisper.

## Project Structure

- `app/`: Flask web application
- `separation/`: Demucs separation logic
- `evaluation/`: SDR + WER evaluation scripts
- `data/`: Audio storage and results
- `notebooks/`: Research and experiment notebooks
- `docs/`: Technical documentation
